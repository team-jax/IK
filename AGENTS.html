역운 — 휴머노이드 상체 로봇 프로젝트

Purpose

양팔 휴머노이드 상체 로봇의 소프트웨어 레포지토리. MuJoCo 시뮬레이션 기반 IK 검증, 웹캠 손목 추적 → UDP → MuJoCo 실시간 동기화 데모(7DOF 팔 + 3손가락 그리퍼, 손 모양으로 쥐기/펴기 제어) + 웹 대시보드 시각화, STM32/Jetson 통합 설계 문서를 포함한다. Phase 2(7DOF 팔 IK + 그리퍼 kinematics)까지 구현됨; Phase 3(실제 모터 연동)은 미착수.

Working In This Directory

  • Python은 반드시 venv/bin/python 사용 (전역 python 금지). macOS에서 MuJoCo viewer가 필요한 스크립트는 venv/bin/mjpython 사용.
  • 새 패키지 설치 시 venv/bin/pip install <pkg>. requirements.txt 없음 — venv에 직접 설치.
  • 코드 수정 시 CLAUDE.md, haness.md의 규칙 준수 필수. haness.md는 AI가 지켜야 할 작업 프로토콜.
  • 파라미터(UDP 포트, 좌표 스케일 등) 변경 시 vision_sender.py, mujoco_receiver.py, web_dashboard.py 모두 확인 — 포트 번호가 세 파일에 하드코딩되어 있어 한 곳만 바꾸면 불일치 발생.
  • vision_sender.py는 mediapipe의 레거시 mp.solutions API가 아닌 Tasks API(PoseLandmarker)를 사용 — mediapipe>=0.10.30에서 레거시 API가 제거됨.

Testing Requirements

  • vision_sender.py: venv/bin/python vision_sender.py — 웹캠 + pose_landmarker_full.task 필요, ‘q’ 키로 종료.
  • mujoco_receiver.py: venv/bin/mjpython mujoco_receiver.py (macOS) — 로컬 디스플레이 필요, arm/arm.xml의 7DOF 팔을 실시간 IK로 구동.
  • web_dashboard.py: venv/bin/python web_dashboard.py — 브라우저에서 http://127.0.0.1:8000 접속.
  • 전체 파이프라인 확인: run_receiver.sh → run_sender.sh(+ 선택적으로 run_web.sh) 순서로 각각 별도 터미널에서 실행 (자세한 순서는 실행방법.txt 참고).
  • test.py: venv/bin/mjpython test.py — gymnasium 설치 확인용.

Common Patterns

  • UDP 통신: socket.SOCK_DGRAM, 패킷 포맷 "x y z curl_index curl_middle curl_ring" (공백 구분 float 6개 문자열). 수신 측(mujoco_receiver.parse_packet, web_dashboard.udp_listener)은 구형 4필드 "x y z grip" 패킷도 받아 grip을 3손가락에 동일 적용(하위 호환). vision_sender.py는 동일 패킷을 5005(mujoco_receiver, 논블로킹 수신)와 5006(web_dashboard) 양쪽에 fan-out. 패킷 필드 개수를 바꾸면 세 파일 모두 파싱 로직을 같이 맞춰야 함 — 안 그러면 ValueError가 조용히 삼켜져(catch 후 continue) 수신 측이 멈춘 것처럼 보임.
  • 손목 좌표 안정화: visibility 필터(MIN_VISIBILITY) → 통과 프레임만 EMA 스무딩(EMA_ALPHA) → 전송. 필터 없이 저신뢰 프레임을 그대로 보내면 팔이 “flapping”함.
  • 손가락 curl 추출: HandLandmarker에서 손가락별로 (fingertip-to-wrist 거리) / (자기 MCP-to-wrist 거리) 비율을 구해 CURL_OPEN_REF(2.0)/CURL_CLOSED_REF(0.7) 사이로 선형 매핑 + clip — 검지(5→8)/중지(9→12)/약지(13→16), 손가락별 자기 MCP로 정규화해 서로 독립. 손이 감지 안 되면 마지막 curl 값들을 유지(hold), 0으로 스냅하지 않음.
  • 좌우 캘리브레이션: mujoco_receiver.py는 첫 UDP 패킷의 x좌표를 중심으로 자동 캘리브레이션, 뷰어 창에서 ‘C’ 키로 언제든 재캘리브레이션 가능.
  • IK 실패 시 폴백: solve_ik 결과가 NaN이거나 예외 발생 시 마지막으로 성공한 last_good_qpos를 그대로 사용해 팔이 튀지 않도록 함.
  • 그리퍼 구동: mujoco_receiver.py의 apply_grip()이 curl 3개(검지/중지/약지 순, FINGER_ORDER = finger1/2/3)를 받아 arm/arm.xml의 6개 finger 관절(fingerN_joint1/2)을 이름으로 직접 씀 — arm.ik.apply_pose()는 qpos[:7]만 쓰므로 서로 겹치지 않음(arm.xml 로드 시 model.nq == 13: 팔 7 + 손가락 6, 순서 보장). MAX_CURL 값은 실측(그립 0→1 스윕하며 fingertip이 중심축으로 단조 수렴하는지 확인)으로 튜닝된 값이라, 그리퍼 지오메트리(finger 세그먼트 길이/반경)를 바꾸면 재튜닝 필요 — 너무 크면 손가락이 중심축을 넘어가 다시 벌어짐.
  • 뷰어 카메라: mujoco_receiver.py가 시작 시 free camera를 CAM_LOOKAT(팔 작업공간 중심)으로 조준 — MuJoCo 기본 프레이밍은 바닥 평면까지 포함해 팔이 화면 위쪽에 치우침. ‘T’ 키로 mjCAMERA_TRACKING(trackbody=gripper_base) 토글. key callback은 뷰어 스레드에서 도는 만큼 플래그만 바꾸고, 실제 viewer.cam 변경은 메인 루프에서 viewer.lock() 안에서 적용.
  • MuJoCo qpos 쓰기 시 반드시 viewer.lock() 컨텍스트 내에서 수행.
  • MuJoCo passive viewer: mj_step 호출 없이 viewer.sync() + time.sleep(0.01) 루프.
