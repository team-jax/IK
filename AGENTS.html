역운(逆運) — 휴머노이드 상체 로봇 프로젝트 (Team JAX)

Purpose

물건을 집어 목표 위치에 놓는 휴머노이드 상체 로봇의 소프트웨어 레포지토리. 팀의 최종 URDF(URDF_1006)를 원본으로, 두 개의 독립된 시뮬레이션 작업(동작 1, 동작 2)이 같은 로봇(7DOF 팔 + 3손가락 손)을 쓴다. 실제 하드웨어(STM32/Jetson/AK45)는 설계만 CLAUDE.md에 있고 코드는 아직 없다.

For AI Agents

Working In This Directory

  • 의존 방향은 motion1 → motion2/arm/make_arm_urdf.py → URDF_1006 하나뿐이다. motion2는 motion1을 import하지 않는다.
  • Python은 항상 루트 venv/bin/python, macOS에서 MuJoCo 뷰어를 띄우는 스크립트는 venv/bin/mjpython. 패키지는 venv/bin/python -m pip install. 폴더를 옮기거나 이름을 바꾸면 venv/bin/pip·mjpython 등의 셔뱅이 깨진다(STATUS.md 참고).
  • 원격 저장소는 origin = https://github.com/team-jax/IK(main). 이전 team-jax/CV_TEST2는 upstream으로 남아 있다.
  • motion1/은 자체 .git(원격 gyumingim/Humanoid_Grasp_RL)이 있다. 루트 저장소에서는 untracked로 보이고 team-jax/IK에는 올리지 않으며, 동작 1 변경은 그 안에서 커밋한다. motion1/이 없는 클론에서도 motion2/는 그대로 동작한다.
  • 문서와 코드가 어긋나면 코드와 실제 실행 결과가 기준이다. 숫자(성공률 등)는 직접 재현한 것만, 측정한 날짜와 시드 범위를 함께 적는다.
  • 새 AGENTS.md를 만들면 첫 줄에 부모를 가리키는 Parent 주석 태그(다른 AGENTS.md와 같은 형식)를 달고 check_docs.py의 DOCS 목록에도 넣는다. 부모 경로는 모든 AGENTS.md에서 검사하지만 기호·경로 대조는 목록의 문서만 한다. 검사기는 문서에서 처음 나오는 “Parent” + 콜론 + 공백 뒤의 단어를 부모 경로로 읽으므로 본문에 그 형식의 예시를 적지 않는다. 이 파일을 고쳤으면 quarto render AGENTS.md로 AGENTS.html도 다시 만든다.

Testing Requirements

저장소 루트에서, 화면·웹캠 없이: ./run_tests.sh (빠른 모드, 약 1분). 성공률과 영상까지 보려면 --full, 뷰어를 열어 보려면 --viewers. 코드나 문서를 고친 뒤에는 반드시 돌린다. 개별 검사: - venv/bin/python motion1/scripts/smoke_test.py - venv/bin/python motion2/arm/ik.py (IK 오차 0.00 mm) - venv/bin/python motion2/scripts/check_grasp.py (lifted 9 /9), check_teleop.py (3/3), check_sender.py, check_dashboard.py (같은 폴더) - venv/bin/python check_docs.py (문서 대조)

Common Patterns

  • 로봇 모델 파일(motion2/arm/arm.xml, arm.urdf, meshes/)은 생성물이다. 고칠 때는 motion2/arm/make_arm_urdf.py의 상수를 바꾸고 다시 생성한다.
