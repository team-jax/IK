* 팔 끝에 손가락 3개짜리 손이 달려있습니다 (최종 URDF 모델).
  카메라 앞에서 검지/중지/약지를 각각 굽히면 그리퍼의 손가락 3개가
  하나씩 따로 따라 움직입니다. (검지→1번, 중지→2번, 약지→3번 손가락)
  엄지/새끼손가락은 무시됩니다.

* MuJoCo 뷰어 카메라는 시작할 때 팔이 화면 중앙에 오도록 맞춰져 있습니다.
  뷰어 창에서 T 키: 그리퍼(손끝)를 계속 따라다니는 카메라 켜기/끄기
  뷰어 창에서 C 키: 좌우 중심 + 팔꿈치 기준각 재캘리브레이션

* 이제 손목뿐 아니라 어깨-팔꿈치-손목(팔 전체)을 추적합니다. 팔꿈치를 옆으로
  벌리거나 모으면 로봇 팔꿈치도 같이 벌어집니다 (7자유도 중 남는 1자유도 활용).
  시작/재캘리브레이션 때의 팔꿈치 자세가 기준(0°)이 되니 편한 자세에서 시작하세요.
  어깨/팔꿈치가 화면에 안 보이면 자동으로 손목만 따라갑니다.
  로봇 팔꿈치가 벌어지는 범위는 기준에서 ±40°까지이고, 손가락을 쥐고 있는 동안(큐브를 잡고 있을 때)은
  팔꿈치가 고정됩니다. 손을 펴면 다시 따라갑니다. 큰 팔꿈치 움직임이 파지를 흔들기 때문입니다.

순서: 터미널 3개 열기 → 1번 먼저 실행 → 2번(또는 3번) 실행 → 3번(또는 2번) 실행
(2번, 3번은 순서 상관없음. 1번만 먼저.)

--------------------------------------------------
스케일 조정 (팔 움직임 범위가 이상할 때)
--------------------------------------------------
mujoco_receiver.py 상단의 숫자를 바꾸고 다시 실행:

LATERAL_SCALE = 0.6   ← 좌우 범위
HEIGHT_SCALE  = 0.085 ← 상하 범위 (손가락을 아래로 유지할 수 있는 높이까지만)
DEPTH_SCALE   = 0.3   ← 앞뒤 범위
BASE_Z        = 0.255 ← 손가락 패드가 큐브 옆면에 오는 파지 중심 높이

그리퍼 열림/닫힘이 이상하면 FINGER_OPEN / FINGER_CLOSED / DISTAL_SCALE 를 조정.
바꾼 뒤에는 ../venv/bin/python check_grasp.py 로 파지 확인 (9/9 이어야 함. DISTAL_SCALE 0.3은 실패).

* 로봇 모델은 최종 URDF(../URDF_1006)에서 생성됩니다. URDF를 바꿨다면
  ../venv/bin/python arm/make_arm_urdf.py  를 다시 실행하세요.
